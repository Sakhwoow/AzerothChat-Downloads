# Azeroth Chat для iPhone — загрузки

Это отдельный раздел для загрузок приложения. Исходники находятся в приватном репозитории.

- [Официальная инструкция AltStore Classic для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)

Публичного релиза IPA пока нет. Готовый IPA собран без подписи; AltStore подпишет его вашим Apple ID при установке. Требуется iOS 16 или новее. Установка на реальном iPhone пока не проверена.
