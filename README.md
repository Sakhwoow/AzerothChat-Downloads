# Azeroth Chat для iPhone — загрузки

Здесь опубликован только собранный IPA приложения для личной установки через AltStore Classic. Исходники находятся в отдельном приватном репозитории.

- [Скачать последнюю сборку IPA](https://github.com/Sakhwoow/AzerothChat-Downloads/releases/latest)
- [Официальная инструкция AltStore Classic для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)

IPA собран без подписи. AltStore подписывает его вашим Apple ID при установке. Требуется iOS 16 или новее. Установка на реальном iPhone пока не проверена.
